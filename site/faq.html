FAQ

Frequently asked questions

What is AuditSaas?

A local CLI that scans a codebase for security, privacy, AI-abuse, payments, and production-readiness gaps — the kind of issues AI coding assistants (Cursor, Claude Code, v0, Lovable, Bolt, etc.) tend to skip. It runs 46 rules across 20 categories and writes the results as Markdown and JSON reports directly into your project.

Does my code ever leave my machine?

No, not by default. The core scanner reads your files locally and never makes a network call. The only exception is the optional AI second-pass review, which is off unless you explicitly configure it — and even then you can point it at a local model (Ollama, LM Studio) instead of a hosted API, so nothing has to leave your machine even with AI review on.

Why is it invite-only right now?

AuditSaas is in private beta. We're still tightening false-positive rates and expanding rule coverage, and we'd rather do that with a smaller group of real users giving direct feedback than with an open public launch.

How do I get access?

Request access via the waitlist form. Once approved, we'll email you an install package — no GitHub account or repo access needed for most testers.

What do I get after I'm approved?

An auditsaas-<version>.tgz file by email. Install it with npm install -g auditsaas-<version>.tgz, then run saas-audit scan . in any project. That's the whole setup.

What does it actually check?

Auth (password hashing, login rate limits, session expiry, cookie flags), authorization/IDOR, API validation, SQL injection and XSS, secrets exposure, CORS/SSRF/CSRF, JWT misconfiguration, dependency and supply-chain risk, file upload handling, admin/debug surface exposure, infra misconfiguration, Stripe webhook signature and idempotency checks, AI/LLM cost and prompt-injection exposure, and privacy/data-collection inventory with policy drafting. See the rule catalog for examples.

Is it free?

Yes, during the private beta — there's no pricing yet. When AuditSaas exits beta, expect a free tier plus paid tiers for full rule coverage and team use; beta testers will be grandfathered in.

Will this replace a real security audit or pentest?

No. AuditSaas is a fast, automated first pass that catches common, well-understood mistakes before they ship. It's a complement to (not a replacement for) a professional security review, especially for anything handling sensitive data at scale.

I think a finding is wrong (false positive/negative) — what do I do?

Reply to your invite email or reach out at beta@auditsaas.org with the rule ID and a bit of context. False-positive reports are exactly what the beta is for.

I found a security issue in AuditSaas itself — how do I report it?

See our security and disclosure page for how to report it responsibly.

Is AuditSaas open source?

Not currently — it's a private beta under an all-rights-reserved license (see Terms). This may change after the beta period.

What frameworks and stacks does it understand?

It auto-detects common SaaS stacks: Next.js/Remix/Express/Fastify, Clerk/NextAuth/Supabase Auth/Firebase Auth, Prisma/Drizzle/Supabase/Mongo/Postgres/MySQL, Stripe/Paddle/Lemon Squeezy, and OpenAI/Anthropic/Gemini/LangChain/Vercel AI SDK — then only runs the relevant rules.
