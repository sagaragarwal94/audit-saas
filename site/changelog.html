What's new

Have a request? See Feedback & feature requests.

July 2026

  • Rule catalog grew to 66 rules across 23 categories (from 46/20) — added JWT expiration checks, non-cryptographic token randomness, OAuth CSRF (state parameter), unauthenticated WebSocket handlers, exposed Swagger UI and health-endpoint info leaks, npm install-time script risk, hardcoded cloud credentials, exposed backup files, public Terraform S3 buckets and open security groups, CSP unsafe-inline/eval, exposed production source maps, missing SRI on external scripts, Stripe client-trusted checkout amounts, unbounded list queries, GraphQL depth limiting, and unauthenticated Next.js Server Actions.
  • Light mode — a theme toggle in the nav, defaulting to your OS preference and remembered across visits.
  • Local-LLM AI review — point the optional AI review step at a local model server (Ollama, LM Studio) instead of a hosted API key.
  • SARIF export (findings.sarif.json) for GitHub code scanning and other CI tooling.
  • Reduced false positives from documentation, test files, and properly gitignored local .env files — behavior-based rules now scope to real application code.
  • FAQ, Privacy Policy, Terms, and Security/disclosure pages published ahead of public launch.
